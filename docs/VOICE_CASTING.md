# 角色聲線建議

在系列的「整系列聲線設定」按「依角色資料建議聲線」，系統會先填入聲線選單並顯示
各角色的選擇理由。你可以繼續修改、還原，確認後再按「儲存整系列聲線」。
建議本身不寫入資料，也不合成音訊；保存後沿用既有的固定聲線與不可變 cast revision
流程，下一批配音才會使用新設定。

建議使用該角色已連結、啟用中的角色庫資料，只考慮與旁白相同引擎、正式可用的聲線：

- 已明確填寫的男／女性別，對應目錄中的男／女聲標籤；未填寫或無法辨識的設定不從名字推測。
- 明確數字年齡（例如 `20`、`20 歲`）可與目錄的年齡範圍比對；不把「看起來年輕」換算成年齡。
- 個性／說話風格用逗號、頓號、分號或換行分開的完整詞組，可與目錄風格標籤比對。例如 `健談、活潑` 可匹配這兩個標籤，`不安靜` 不會匹配 `安靜`。
- 同等匹配時優先使用旁白語系、保留既有相符聲線，再分散重複聲線；聲線不足仍可共用。主要角色優先處理，輸入排列不同不會造成隨機選角。

沒有明確相符資料、沒有角色庫連結或角色庫已停用時，保留目前選擇並說明原因。
本次手動調整過的聲線也會保留。3wa 克隆聲線需人工確認已就緒與授權，這個按鈕不替代
Clone 準備流程。這是規則式建議，沒有呼叫 LLM 或外部 TTS 分析角色資料。

## 聲線目錄的可選欄位

`SeriesVoiceCatalog:Voices` 每一筆可增加下列欄位，不改變原本的 Provider／Voice identity：

| 欄位 | 意義 |
|---|---|
| `Gender` | `male`、`female`、`neutral` 或省略；目前角色男／女設定只匹配對應標籤 |
| `MinimumAge`／`MaximumAge` | 選角偏好的年齡範圍，0～150，起點不得大於終點；可省略 |
| `CharacterTags` | 最多 16 個不重複的完整風格標籤，每個最多 40 字元；可省略 |

內建 Edge／BlueMagpie 聲線只補上原目錄已明示的男／女聲標籤；沒有替模型猜測年齡、
個性或演技。VoAI 與克隆入口維持沒有性別標籤。年齡與風格需由維護者依實際聲線資料
設定，未提供就不使用該項評分。這些是選角偏好，並非模型能力保證。

本機以合成角色與聲線資料驗證建議、手動保留、還原、儲存後重新開啟及切換系列時的
晚到回應；Chromium 檢查 1440／390／320px 排版。這不代表實際聲線品質或正式站已驗收。
