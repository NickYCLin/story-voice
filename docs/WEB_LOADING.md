# 工作頁面載入

登入後的書庫、書冊、分享、角色、系列配音與 developer 工作頁面依路由載入 JavaScript。
首頁、公開聲線入口與開發者文件保留在初始入口。登入確認完成後才掛載私人頁面，API
仍執行原本的帳號與 owner 存取檢查。

下載頁面模組時，導覽列與帳號操作維持可用，內容區顯示「頁面載入中…」。若模組下載
或頁面渲染失敗，顯示可重新整理的提示；使用者也可直接切換到其他頁面。重新整理會
再次載入整個頁面，不會在失敗時自動反覆重新整理，也不顯示內部錯誤內容。

錯誤狀態會隨路徑或 query 變更重設，正常頁面不因這個重設機制被額外卸載。因此既有
頁面自己保留的篩選、選取與表單狀態，仍由該頁面的路由處理決定。

2026-09-08 的本機正式建置中，入口 JavaScript 從 553.59 kB 降至 306.09 kB，gzip 從
159.77 kB 降至 97.35 kB；最大私人頁面模組約 58 kB，共用功能另有共用模組。
這些數字的測量範圍是建置產物大小，實際下載時間與總流量仍取決於網路、快取及使用的頁面。

測試涵蓋延遲載入、失敗後切換頁面、正常內容狀態保留，以及匿名時不載入私人頁面。
根路徑與 `/StoryVoice/` 子路徑的正式建置另以 Chromium 模擬模組下載失敗、重新整理
恢復與 1440／390／320px 排版。
